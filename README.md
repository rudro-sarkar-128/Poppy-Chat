# Poppy-Chat
A real-time communication web app built with WebRTC and WebSockets. poppy-chat offers instant messaging, private rooms for one-on-one audio/video calls, and screen sharing capabilities. This is my first project exploring peer-to-peer media and real-time communication technologies.

## Features

- **Real-time Messaging** – Send and receive messages instantly with WebSockets.
- **Private Rooms** – Create or join a room for one-on-one communication.
- **Audio/Video Calls** – High-quality peer-to-peer calls using WebRTC.
- **Screen Sharing** – Share your screen seamlessly during video calls.

## Tech Stack

- **Frontend**: HTML, CSS, JavaScript (Used ChatGPT for designing)
- **Backend**: Node.js, Express
- **Real-time Communication**: WebRTC, WebSockets (using socket.io)
